## 事務アプリ（My柔道(事務)）1.3

```
■ 予定表のリンクを合言葉で守れるようになりました
・LINEなどで送る予定表のリンクを、道場の合言葉で暗号化できます。合言葉を知らない人は、リンクを持っていても中身を見られません。
・合言葉は「予定を共有」の画面か「設定 › セキュリティ」から、いつでも登録・変更できます。
・送るリンクの長さを約半分にしました。

■ 学年の計算を正しくしました
・入学年度が1年早く計算される不具合を直しました。すでに保存された学年も自動で直します（手で入力された学年はそのままです）。直す前の控えを残します。

■ 保存できないときに気づけるようにしました
・データが読み込めなかったときは画面の上でお知らせし続け、入力した内容が黙って消えないようにしました。
・読めなかったデータは「設定 › データ管理」から書き出せます。

■ 使いやすくしました
・下のタブやカレンダーの文字を大きくし、小さなボタンも押しやすくしました。
・くり返し登録を「○日ごと」の表示にし、何件登録されるかを先に確かめられるようにしました。
・年度アーカイブや申込のまとめ変更など、取り返しのつかない操作の前に内容を確かめる画面を足しました。
・iPhoneでスクロールしたときに、画面の上下の枠が動いてしまうのを直しました。

■ 直した不具合
・試合報告で、何も選んでいない行が「勝ち」として送られることがあったのを直しました。
・写真やQRコードの共有が、iPhoneで黙って失敗することがあったのを直しました。
・パスコードロックが、起動の失敗やアプリの切り替えのあとにかからないことがあったのを直しました。
・団体戦の人数を変えたときに、記入済みの枠がずれたり消えたりするのを直しました。
・試合結果の取り込みで、名字だけが一致した別の選手が自動で選ばれることがあったのを直しました。
・そのほか、表示と翻訳の細かな修正を多数行いました。
```

## 提出時の注意

- 輸出コンプライアンス：`ITSAppUsesNonExemptEncryption` は両アプリとも `false`。
  暗号は WebCrypto（iOS が用意しているもの）だけを呼んでおり、暗号のライブラリは同梱していない。
  そのため App Store Connect では質問が出ない見込み。
- 広告ID（IDFA）：使っていない（RevenueCat は広告IDを取得しない）。
- スクリーンショット：前の版のものが引き継がれる。今回は差し替えない。
